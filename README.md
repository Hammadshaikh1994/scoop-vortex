# 🪣 Official Scoop Bucket for Vortex Downloader

This repository serves as the official [Scoop](https://scoop.sh) bucket for **[Vortex Downloader](https://vortexdownloader.org)**.

## 🚀 Installation via Scoop

### 1. Add this Bucket
```powershell
scoop bucket add vortex https://github.com/Hammadshaikh1994/scoop-vortex
```

### 2. Install Vortex Downloader
```powershell
scoop install vortex
```

### 3. Update Vortex Downloader
```powershell
scoop update vortex
```

## 📦 About Vortex Downloader
